# Neurosymbolic AI (direct te gebruiken)

Dit project bevat een **direct bruikbare Neurosymbolic AI** in Python, zonder externe libraries.

## Wat dit doet

- **Neuraal component**: intent-detectie via gewogen token-scoring.
- **Symbolisch component**: transparante IF-THEN regels met prioriteiten.
- **Output**: intent, confidence, geactiveerde regels en concreet advies.

## Snel starten

```bash
python neurosymbolic_ai.py "Ik heb koorts en hoofdpijn"
```

Interactieve modus:

```bash
python neurosymbolic_ai.py --interactive
```

## Waarom neurosymbolic?

- Het neurale deel herkent patronen/intent.
- Het symbolische deel legt expliciete logica en veiligheidsregels vast.
- Samen krijg je beter uitlegbare AI met praktische, directe antwoorden.

## Let op

Deze demo geeft algemene suggesties en is **geen medisch, juridisch of financieel professioneel advies**.
